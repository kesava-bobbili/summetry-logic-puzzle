Rules

Fill the grid so that every row, every column, and both diagonals add up to the same target sum. Repeating numbers is allowed as long as the values stay within the allowed range for the selected grid size.

How It Works

  1. Pick a grid size and a difficulty level.
  2. Every row, column, and diagonal must hit the target sum.
  3. Values must stay within the allowed range for that grid.
  4. Use up to 3 hints when stuck.
  5. Fixed cells cannot be changed.

Difficulty

Easy: about 50–60% of cells are prefilled.

Medium: about 35–45% prefilled.

Hard: about 20–30% prefilled.

Feedback

Green means the line or cell matches the target.

Red means a completed line misses the target.
